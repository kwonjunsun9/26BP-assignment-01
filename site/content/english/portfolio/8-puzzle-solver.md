## 프로젝트 소개

**8-Puzzle Solver**는 숫자 타일을 목표 순서로 정렬하는 8-퍼즐을 대상으로, 탐색 알고리즘의 동작과 해결 과정을 살펴보는 프로그램입니다.

8-퍼즐은 3×3 격자에 숫자 타일 8개와 빈칸 하나를 배치한 퍼즐입니다. 빈칸과 인접한 타일을 움직여 목표 상태에 도달하는 것이 목적입니다. 이 프로젝트에서는 Python으로 퍼즐 상태와 탐색 문제를 다루고, 콘솔 실행과 Pygame 기반 GUI를 통해 해결 과정을 표현합니다.

```text
초기 상태             목표 상태

1  2  3              1  2  3
4  □  6      →       4  5  6
7  5  8              7  8  □
```

## 주요 기능

- **랜덤 퍼즐 생성**: 새로운 퍼즐을 생성해 다양한 초기 상태에서 탐색 과정을 살펴봅니다.
- **탐색 방식 선택**: DFS, BFS, UCS, A*를 선택하는 인터페이스로 서로 다른 탐색 방식을 다룹니다.
- **해결 과정 시각화**: Pygame GUI에서 타일이 이동하는 과정을 애니메이션으로 확인합니다.
- **실행 제어**: New Puzzle, Stop, Reset 버튼으로 새 퍼즐 생성, 일시 정지, 초기화를 수행합니다.
- **콘솔 실행**: 초기 상태와 알고리즘, 결과 파일 경로를 지정하는 실행 방식을 제공합니다.

## 프로젝트에서 다루는 탐색 알고리즘

| 알고리즘 | 탐색 기준 | 살펴볼 수 있는 차이 |
| --- | --- | --- |
| DFS · 깊이 우선 탐색 | 깊은 경로를 우선 탐색 | 탐색 순서에 따라 발견되는 경로가 달라집니다. |
| BFS · 너비 우선 탐색 | 시작 상태에서 가까운 깊이부터 탐색 | 이동 비용이 같을 때 최단 이동 경로를 찾습니다. |
| UCS · 균일 비용 탐색 | 누적 비용이 작은 경로를 우선 탐색 | 누적 비용을 기준으로 탐색 순서를 정합니다. |
| A* · A-Star 탐색 | 누적 비용과 남은 비용의 추정치를 함께 고려 | 휴리스틱이 탐색의 우선순위에 어떤 영향을 주는지 살펴봅니다. |

## 구현 구조

| 파일 | 역할 |
| --- | --- |
| `search.py` | 탐색 알고리즘과 휴리스틱 함수를 다루는 모듈 |
| `eightpuzzle.py` | 퍼즐 상태와 탐색 문제를 정의하는 모듈 |
| `main.py` | 콘솔 실행 진입점 |
| `main_ui.py` | Pygame GUI 실행 진입점 |

퍼즐 상태는 `EightPuzzleState`, 탐색 문제는 `EightPuzzleSearchProblem`으로 나뉩니다. 탐색 알고리즘은 문제 정의와 분리되어, 같은 퍼즐 문제에 서로 다른 탐색 방식을 적용할 수 있는 구조입니다.

## 핵심 설계 포인트

**퍼즐을 상태 공간으로 표현하기**  
각 타일 배치를 하나의 상태로 보고, 빈칸의 상·하·좌·우 이동으로 다음 상태를 연결합니다. 목표는 상태를 찾는 데서 끝나지 않고, 목표까지의 이동 순서를 구하는 것입니다.

**중복 상태를 다루는 그래프 탐색**  
퍼즐은 같은 배치로 되돌아올 수 있으므로 방문 상태를 관리하는 것이 중요합니다. 같은 상태를 반복해서 탐색하지 않도록 방문 여부를 관리하고, 목표까지의 경로를 `up`, `down`, `left`, `right`로 구성된 동작 목록으로 표현하는 것이 핵심입니다.

**탐색 결과를 눈으로 확인하기**  
숫자와 경로를 콘솔에서 확인하는 방식에 더해 GUI 애니메이션으로 타일의 이동을 표현합니다. 이를 통해 알고리즘이 구한 경로를 퍼즐의 움직임으로 이해할 수 있습니다.
